Limpieza y perfilado de datos

Proyecto practico de limpieza de datos enfocado en cargar, explorar, diagnosticar y preparar un dataset para analisis. El trabajo utiliza Pandas para la depuracion y ydata-profiling para generar un reporte automatico de calidad, distribuciones, duplicados, valores faltantes e integridad general.

Herramientas: Python, Pandas, ydata-profiling Tipo: Data cleaning Salida: dataset limpio y reporte HTML

Objetivo

Preparar datos confiables antes del analisis

El objetivo del proyecto fue aplicar un flujo basico pero necesario de limpieza de datos: cargar la fuente, inspeccionar su estructura, detectar problemas de calidad, manejar duplicados, revisar columnas faltantes y validar integridad antes de generar una version lista para analisis.

Proceso

Trabajo realizado

  • Carga inicial: lectura del dataset con Pandas y revision de dimensiones, tipos de datos y primeras filas.
  • Exploracion: analisis de estructura, columnas, valores unicos y estadisticas descriptivas.
  • Duplicados: identificacion y tratamiento de registros duplicados para evitar conteos inflados.
  • Valores faltantes: deteccion de columnas incompletas y evaluacion de su impacto en el analisis.
  • Integridad: revision de consistencia en columnas clave, tipos de datos y posibles valores fuera de rango.
  • Perfilado automatico: generacion de un reporte HTML con ydata-profiling para documentar hallazgos.
  • Salida limpia: exportacion de una version procesada del dataset para analisis posterior.

Python

Fragmentos representativos

import pandas as pd

df = pd.read_csv("data/raw/source.csv")

df.head()
df.info()
df.describe(include="all")
duplicados = df.duplicated().sum()
faltantes = df.isna().sum().sort_values(ascending=False)

print("Duplicados:", duplicados)
print(faltantes)
df_clean = (
    df
    .drop_duplicates()
    .copy()
)

df_clean.columns = (
    df_clean.columns
    .str.strip()
    .str.lower()
    .str.replace(" ", "_")
)
from ydata_profiling import ProfileReport

profile = ProfileReport(
    df_clean,
    title="Data Cleaning Report",
    explorative=True
)

profile.to_file("reports/data_cleaning_report.html")

Calidad

Validaciones realizadas

El reporte de ydata-profiling se uso como apoyo para identificar problemas que no siempre se detectan en una revision manual rapida.

  • Porcentaje de valores faltantes por columna.
  • Distribuciones y posibles valores atipicos.
  • Columnas constantes o con baja variabilidad.
  • Correlaciones entre variables numericas.
  • Tipos inferidos y posibles inconsistencias.
  • Duplicados y cardinalidad de variables categoricas.

Entregables

Salida del proyecto

  • Notebook o script: flujo de limpieza reproducible en Python.
  • Dataset limpio: archivo procesado para analisis posterior.
  • Reporte HTML: perfil automatico generado con ydata-profiling.
  • Documentacion: resumen de problemas encontrados y decisiones de limpieza.

Aprendizajes

Decisiones tecnicas

  • Separar la inspeccion inicial de la limpieza ayuda a no modificar datos sin entenderlos primero.
  • Los duplicados deben validarse con contexto, no eliminarse a ciegas.
  • Los valores faltantes no siempre se imputan; a veces conviene conservarlos o excluir columnas segun el objetivo.
  • Un reporte automatico acelera el diagnostico, pero las decisiones finales requieren criterio analitico.
  • Documentar la limpieza hace que el proceso sea reproducible y defendible.
